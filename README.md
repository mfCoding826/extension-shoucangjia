# 📑 智能收藏夹 — Chrome 浏览器扩展

自动识别书签页面类型、生成 AI 摘要，实时同步到飞书多维表格。

## 功能概览

- **📌 自动同步**：收藏网页时自动触发，无需手动操作
- **📥 批量导入**：支持导入 Chrome 导出的书签 HTML 文件，一次性批量同步全部书签
- **🏷️ 智能分类**：调用大模型自动判断页面类型（科技、教育、AI、财经等 50+ 类别）
- **📝 内容摘要**：AI 自动生成 100 字以内的页面核心要点
- **☁️ 云端存储**：数据实时写入飞书多维表格，多设备随时查看
- **🔌 多模型支持**：内置 22 家模型厂家（DeepSeek、OpenAI、智谱、通义千问、豆包等）+ 自定义选项
- **⚙️ 灵活配置**：可视化配置页，所有参数动态可调，实时生效
- **📊 用量控制**：可调节的每日 API 调用上限，防止意外超支
- **📋 运行日志**：内置日志面板，可查看每次收藏的完整处理链路和错误详情

## 准备工作：注册飞书应用

> 本教程假设你已有飞书账号。如果没有，请先在 [飞书官网](https://www.feishu.cn/) 注册（个人免费版即可）。

### 第一步：进入飞书开发者后台

1. 打开浏览器，访问 **https://open.feishu.cn/**
2. 点击右上角的「**登录**」按钮
3. 使用飞书扫码或手机号登录
4. 登录后，你会进入**飞书开放平台**首页

### 第二步：创建企业自建应用

1. 在左侧菜单栏，点击「**开发者后台**」
2. 进入后，点击右上角的「**创建应用**」按钮
3. 在弹出的页面中，选择「**企业自建应用**」
4. 填写应用信息：
   - **应用名称**：填写 `智能收藏夹`（或任意名称）
   - **应用描述**：填写 `自动同步浏览器书签到多维表格`
   - **应用图标**：可上传任意图片（仅后台显示）
5. 点击「**确认创建**」

### 第三步：获取 App ID 和 App Secret

1. 创建成功后，自动进入应用详情页
2. 在左侧菜单点击「**凭证与基础信息**」
3. 你会在页面右侧看到：
   - **App ID**：以 `cli_` 开头的一串字符，如 `cli_a3b4c5d6e7f8g9h0`
   - **App Secret**：一串加密字符，默认显示为 `●●●●●●●●●●`
4. 点击 App Secret 旁边的「**查看**」按钮，通过手机验证后即可复制
5. ⚠️ **请将这两个值保存到记事本，稍后配置插件时需要用到**

### 第四步：添加权限

1. 在应用详情页左侧菜单，点击「**权限管理**」
2. 点击「**添加权限**」按钮
3. 搜索框输入 `bitable`（多维表格）
4. 勾选以下权限：
   - **bitable:app** — 访问多维表格
5. 点击「**保存**」
6. 系统会提示需要「**创建新版本**」才能生效，先不管，稍后统一处理

### 第五步：创建多维表格

1. 打开飞书网页版 https://www.feishu.cn/ 并登录（桌面客户端操作类似）
2. 在左侧导航栏点击「**云文档**」图标（📄 文档图标）
3. 进入云文档页面后，点击右上角的「**新建**」按钮
4. 在下拉菜单中选择「**多维表格**」
5. 弹出模板选择窗口，点击「**空白多维表格**」
6. 给表格取个名字，如 `我的收藏夹`
7. 创建好之后，你会看到一个空白的多维表格

> 💡 也可以直接在左侧导航栏顶部点击「**+**」号 → 选择「**多维表格**」来创建。

### 第六步：创建数据表并设置列

> 📌 需要创建 **两张** 数据表。

#### 表一：`书签收藏`（同步成功的书签）

1. 在新建的多维表格界面下方，你会看到一个默认的数据表（通常叫「**表格 1**」）
2. 右键点击表名 →「**重命名**」，改为 `书签收藏`
3. 依次创建以下三列，类型全部设为「**文本**」：
   - `页面类型`
   - `页面URL`
   - `页面内容总结`

#### 表二：`同步失败记录`（批量导入时，失败的书签记录在此）

1. 点击表格底部的「**+**」新建一个数据表
2. 命名为 `同步失败记录`
3. 依次创建以下四列，类型全部设为「**文本**」：
   - `书签标题`
   - `页面URL`
   - `失败原因`
   - `失败时间`

### 第七步：获取多维表格 ID（app_token）

1. 在飞书中打开你的多维表格
2. 查看浏览器地址栏的 URL，有新旧两种格式：

   **新版 URL**（以 `/wiki/` 开头）：
   ```
   https://my.feishu.cn/wiki/XXXXXXXXXXXX?table=tblXXXXXXXXXXXX&view=vewXXXXXXXX
   ```
   其中 `/wiki/` 后面到 `?table=` 之前的部分就是 app_token：`XXXXXXXXXXXX`

   **旧版 URL**（以 `/base/` 开头）：
   ```
   https://abc.feishu.cn/base/BascNvJ2oXpQ5hTqR?table=tblxxx
   ```
   其中 `/base/` 后面的部分就是 app_token：`BascNvJ2oXpQ5hTqR`

3. 复制 app_token，保存到记事本

### 第八步：发布应用

1. 回到飞书开发者后台（https://open.feishu.cn/）
2. 在左侧菜单点击「**版本管理与发布**」
3. 点击右上角的「**创建版本**」
4. 填写版本号，如 `1.0.0`
5. 点击「**保存**」
6. 然后点击该版本旁边的「**申请发布**」
7. 确认发布即可

> 🎉 **飞书配置完成！** 你现在有了四个关键信息：App ID、App Secret、多维表格 ID、数据表名称（`书签收藏`）。

## 安装插件

### 开发模式安装

1. 打开 Chrome 浏览器
2. 在地址栏输入 `chrome://extensions/`，回车
3. 打开右上角的「**开发者模式**」开关
4. 点击左上角出现的「**加载已解压的扩展程序**」按钮
5. 在弹出的文件夹选择窗口中，选择本项目的根目录（即包含 `manifest.json` 的文件夹）
6. 点击「选择文件夹」
7. 扩展程序列表中会出现「**智能收藏夹**」卡片，表示安装成功

### 后续更新

如果你修改了代码或更新了版本：
1. 回到 `chrome://extensions/`
2. 找到「智能收藏夹」卡片
3. 点击右下角的「**刷新**」图标（🔄）

## 配置插件

### 打开配置页面

有两种方式打开配置页：
- **方式一**：点击 Chrome 工具栏右上方的扩展图标🧩 → 找到「智能收藏夹」→ 点击图钉📌固定 → 然后点击扩展图标
- **方式二**：在 `chrome://extensions/` 页面，点击「智能收藏夹」卡片上的「**选项**」（或「扩展程序选项」）

### 配置项说明

| 区域 | 配置项 | 说明 |
|---|---|---|
| ☁️ 云文档 | 飞书 App ID | 在飞书开发者后台「凭证与基础信息」中获取，格式 `cli_xxxx` |
| | 飞书 App Secret | 同上，需点击「查看」并验证身份后复制 |
| | 多维表格 ID | 从多维表格 URL 中提取，`/base/` 后的那串字符 |
| | 数据表名称 | 表格中的表名，默认填 `书签收藏` |
| 🤖 大模型 | 模型厂家 | 下拉选择，选择后自动填充模型名称和接口地址 |
| | API Key | 从对应平台获取的密钥 |
| | 模型名称 | 选择厂家后自动填充，自定义模式可手动修改 |
| | Base URL | 选择厂家后自动填充，自定义模式可手动修改 |
| 📊 用量 | 每日 API 上限 | 每次收藏调用 2 次 API（分类+摘要），建议值 50~200 |

### 保存与验证

- 填写完成后，点击底部「**💾 保存配置**」按钮
- 飞书配置可以点击「**🔍 验证连接**」按钮测试是否正确
- 配置保存后**实时生效**，无需重启浏览器或插件

### 查看运行日志

配置页底部有一个「**📋 运行日志**」面板，可以查看插件运行过程中每一步的执行情况。

1. 点击面板标题栏展开日志
2. 日志采用终端风格显示，每条记录包含时间、等级、内容
3. **日志等级说明**：

   | 标识 | 含义 |
   |---|---|
   | 🔵 信息 | 正常操作（书签创建、页面抓取、批量导入等） |
   | 🟢 成功 | 操作成功（LLM 分析完成、飞书写入成功） |
   | 🟡 警告 | 跳过处理或降级（无 URL、用量上限、配置缺失） |
   | 🔴 错误 | 操作失败，显示完整错误原因（API 返回错误码、网络超时等） |

4. 遇到同步失败时，展开日志面板即可看到具体出错环节和原因
5. 点击「🔄 刷新」获取最新日志，「🗑️ 清空」清除历史记录

## 批量导入已有书签

如果你之前已有大量收藏，可以通过导入书签文件一次性全部同步。

### 第一步：导出 Chrome 书签

1. 打开 Chrome 浏览器
2. 点击右上角「**⋮**」→「**书签**」→「**书签管理器**」
3. 在书签管理器页面，点击右上角「**⋮**」→「**导出书签**」
4. 保存为 `.html` 文件到本地

### 第二步：导入并同步

1. 打开插件的配置页面
2. 滚动到「**📥 批量导入书签**」区域
3. 拖拽或点击选择刚导出的 `.html` 文件
4. 确认书签数量后，点击「**🚀 开始批量同步**」
5. 等待处理完成（可实时查看进度条和统计）
6. 成功 → 写入飞书 `书签收藏` 表
7. 失败 → 自动记录到飞书 `同步失败记录` 表，包含失败原因

> 💡 批量导入使用书签标题作为分析内容（不会打开每个页面），分类准确度略低于实时收藏。

## 开始使用

配置完成后，一切就绪：

1. **正常浏览网页**，遇到想收藏的页面
2. **点击地址栏右侧的星标**（或按 `Ctrl+D` / `Cmd+D`）
3. 插件会自动：
   - 抓取页面标题和正文内容
   - 调用大模型识别页面类型
   - 调用大模型生成内容摘要
   - 将结果写入飞书多维表格
4. 完成后会在屏幕右下角弹出通知

打开飞书多维表格，即可实时查看所有收藏记录。

## 常见问题

### Q：点击收藏后没有反应？

1. **优先查看运行日志**：打开配置页 → 展开底部「📋 运行日志」面板，查看是否有错误记录
2. 确认已保存所有配置（云文档 + 大模型）
3. 确认今日 API 用量未达上限
4. 如日志面板无记录，可打开 Service Worker 控制台进一步排查：
   - 访问 `chrome://extensions/`
   - 找到「智能收藏夹」卡片 → 点击「**Service Worker**」链接
   - 在 Console 中查看是否有错误

### Q：飞书验证连接失败？

1. 确认 App ID 和 App Secret 复制完整，不留多余空格
2. 确认多维表格 ID（app_token）正确，来自 URL `/base/` 后
3. 确认应用已在飞书开发者后台「发布」
4. 确认已添加 `bitable:app` 权限并创建了新版本

### Q：大模型调用失败？

1. 确认 API Key 正确，没有过期
2. 确认账户有余额（部分平台赠送额度用完需充值）
3. 确认 Base URL 与所选厂家匹配
4. 尝试切换到其他模型厂家

### Q：表格里没有出现数据？

1. 确认数据表名称与配置中填写的完全一致（区分大小写）
2. 确认数据表中有 `页面类型`、`页面URL`、`页面内容总结` 三个文本列
3. 确认列名与代码中的字段名完全一致

### Q：如何更换模型厂家？

打开配置页 → 在「大模型配置」区域下拉选择新厂家 → 填入对应的 API Key → 保存即可。已配置的云文档设置不受影响。

### Q：每日 API 上限是什么意思？

每次收藏网页，插件会调用 2 次大模型 API（一次分类、一次摘要）。设置上限后，超出则当天不再自动处理新收藏。建议设置 50~200（即 25~100 次收藏/天）。

### Q：批量导入失败了怎么办？

失败的书签会自动写入飞书「**同步失败记录**」表中，包含失败原因和时间。你可以：
1. 打开飞书多维表格，切换到「同步失败记录」表查看详情
2. 根据失败原因修正后，重新导入或手动处理
3. 常见失败原因：API Key 无效、网络超时、页面不存在等

### Q：使用 DeepSeek 等国内模型需要科学上网吗？

不需要。DeepSeek、智谱、通义千问、豆包、Moonshot 等国内厂家的 API 均可直连访问。
